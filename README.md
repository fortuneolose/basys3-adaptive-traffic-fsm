# Basys 3 Adaptive Traffic FSM

A staged SystemVerilog implementation of an adaptive, safety-aware traffic-junction controller for the Digilent Basys 3 FPGA.

This repository is being published as a reconstructed milestone history: each commit isolates a logical engineering stage, while commit timestamps reflect the actual publication time.

## Planned milestones

1. Adaptive Moore FSM
2. Basys 3 board integration
3. Self-checking behavioral verification
4. Reproducible Vivado project automation
5. Waveform and implementation evidence
6. Architecture and interview documentation

> Educational demonstration only. This is not a certified road-traffic controller or functional-safety system.
